Политика

Коротко и честно: что за проект и что он делает с твоими данными.

Открытый код

Исходники лаунчера и этого сайта лежат на GitHub. Каждый релиз собирается из открытого кода — можешь проверить или собрать сам.

Без телеметрии

Лаунчер никуда не отправляет твои данные: ни статистики, ни аналитики, ни трекеров. Сеть используется только для загрузок, которые ты сам запросил.

Откуда качается

Игра и Java — с серверов Mojang. Моды — с Modrinth. Authlib-injector — с GitHub. Обновления лаунчера — с GitHub-релизов. Никаких пересборок и зеркал.

Аккаунты

Офлайн-ник хранится только у тебя. Токены Ely.by лежат в локальном файле и уходят только на серверы Ely.by для входа. Пароли нигде не сохраняются.

Discord

Rich Presence показывает твой статус только если включено в настройках. Выключается в один клик, соединения рвутся сразу.

Бесплатно

NEMO бесплатен целиком: все функции, без премиума и рекламы. Minecraft — отдельная игра Mojang, лаунчер её не раздаёт.
