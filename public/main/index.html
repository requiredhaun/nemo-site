NEMO

Minecraft лаунчер: сборки, моды, шейдеры и темы. Java ставит сам.

…

Windows 10/11 x64 · бесплатно · открытый код

Возможности

Сборки и загрузчики

Изолированные сборки: Vanilla, Fabric, Quilt, Forge, NeoForge. У каждой своя папка, RAM и версия Java.

Каталог Modrinth

Моды, шейдеры, текстурпаки и модпаки — поиск и установка в один клик, плюс импорт .mrpack.

Темы

Тёмная и светлая темы, акцентные цвета, dot-сетка и русский/английский интерфейс.

Discord RPC

Статус «сидит в NEMO / запускает / играет» виден в профиле Discord из коробки.

Автообновление

Лаунчер сам находит новый релиз на GitHub и предлагает обновиться. Пропуск версии — в один клик.

Без Java-заморочек

Нужный рантайм Mojang (8/16/17/21) качается автоматически под каждую версию игры.

Системные требования

  • Windows 10/11, x64
  • ~200 МБ на диске (+ место под сборки)
  • Java не нужна — лаунчер скачает сам
